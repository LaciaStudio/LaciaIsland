# Изменения

## 1.0.0 — 2026-10-09

Первый публичный релиз.

- Остров сверху экрана с «желейной» анимацией на пружинах и режим чёлки (Notch).
- Музыка из системного медиаблока Windows: обложка (обновляется при смене трека), живые полоски под настоящий звук, перемотка, кнопки.
- Звонки, когда программа занимает микрофон: время, уровень голоса, выключение микрофона, переход в приложение.
- Таймер, секундомер и быстрая панель по правому клику.
- Две активности сразу: кружок с перемычкой, свайп меняет их местами.
- Подсказки: громкость (и колесо мыши над островом), раскладка, зарядка, наушники.
- Настройки: размер, длина (и Ctrl + колесо), отступ, монитор, автозапуск, скрытие в полноэкранных приложениях.
- Своя отрисовка в прозрачное окно и свой таймер кадров — анимации стартуют без подвисаний.
